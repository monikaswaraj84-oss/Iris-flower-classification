# Iris Flower Classification Using Machine Learning

## Project Overview

Iris Flower Classification is a Machine Learning project that predicts the species of an Iris flower based on its sepal and petal measurements.

## Technologies Used
- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## Dataset
The project uses the Iris dataset in CSV format, containing four input features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Flower Species
1. Iris Setosa
2. Iris Versicolor
3. Iris Virginica

## Project Workflow
1. Upload the CSV dataset.
2. Load and explore the data.
3. Clean and preprocess the dataset.
4. Visualize the data using graphs.
5. Split the dataset into training and testing sets.
6. Train a K-Nearest Neighbors (KNN) classifier.
7. Evaluate model accuracy.
8. Predict the species of a new flower.

## How to Run
Open the notebook in Google Colab, upload the `iris.csv` file, and execute the code cells in order.

## Expected Outcome
The trained model predicts the species of an Iris flower from its measurements and provides an accuracy evaluation on the test dataset.

## Conclusion
This project demonstrates the practical application of Machine Learning for classification, data analysis, visualization, and prediction.
